# "crimson" OSHW compact foldable mechanical keyboard

## Roadmap
- [x] Schematics mk1 finished
- [x] PCB design mk1 finished
- [ ] 3D printable Chassis designed in CAD
- [ ] Keycaps 3D printable in ABS
- [ ] firmware finished
- [ ] first version assembled irl
- [ ] first version thoroughly tested
- [ ] first version on sale


## Specs
- TKL -> 87 ULP Cherry Tactile Switches
- Foldable -> preferrably in thirds
- 3D printable chassis and caps
- ZMK firmware based on nice!nano V2 Microcontroller
